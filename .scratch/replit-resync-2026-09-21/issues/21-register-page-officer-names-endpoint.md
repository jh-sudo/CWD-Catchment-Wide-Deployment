## What happened

`Register.tsx` (the unauthenticated signup page) still calls the full `/api/roster-plan/officers`
endpoint. This repo's own backend **already has** a purpose-built
`/api/roster-plan/officer-names` endpoint — with a code comment noting it's mid-port from Replit
— that returns a minimal `{id, name, unitCode?, catchment?}` list instead of the full officer
record set to an unauthenticated caller.

## Fix

Switch `Register.tsx` to call `/api/roster-plan/officer-names` instead of the full `/officers`
endpoint. Also add optional-chaining for officers missing `unitCode`/`catchment` while in this
code, since those fields are optional on the minimal endpoint's response.
