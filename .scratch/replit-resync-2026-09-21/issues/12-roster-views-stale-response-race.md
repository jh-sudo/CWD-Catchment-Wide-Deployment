## What happened

`TodaysRoster.tsx`'s and `RosterCycle.tsx`'s `load()`/`loadDate()` have no guard against
out-of-order async responses. Rapidly navigating between dates (repeated next/prev, or a fast
date-picker change) can let an earlier request's response land *after* a later one and overwrite
the current date's state with the wrong date's data; the loading spinner can also be cleared by
whichever request finishes first rather than the most recently requested one.

## Fix

Port Replit's `activeLoadDateRef` pattern: track the most-recently-requested date, drop any
response for a date the user has since navigated away from, and only clear the loading state for
the still-active request. Apply to both `TodaysRoster.tsx` and `RosterCycle.tsx` (same bug in
both — they clearly share a common origin).
