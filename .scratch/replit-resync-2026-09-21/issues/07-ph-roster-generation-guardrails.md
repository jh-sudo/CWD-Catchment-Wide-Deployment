## What happened

Replit's `phRoster.ts` added two self-checks that this repo's `autoAllocate` doesn't have:

- `assertNoHRCrossHolidayDoubleDuty(ref, year)` — throws if the same officer is scheduled for
  both Hari Raya Puasa and Hari Raya Haji in the same year.
- `assertBalancedPHCounts(ref, year, eligibleNames)` — throws if any eligible officer's total
  PH-duty count for the year falls outside the fleet-wide min/max band, or if an ineligible
  officer appears at all.

## Fix

Port both checks into this repo's `autoAllocate` (`artifacts/api-server/src/routes/phRoster.ts`),
run at generation time, throwing (not silently persisting) on violation.
